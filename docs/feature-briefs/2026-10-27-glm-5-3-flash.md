# GLM-5.3-Flash（仅文本）

## Title

GLM-5.3-Flash — Apple Silicon 上的本地文本模型（`glm5_next`）

## One-line pitch

Run GLM-5.3-Flash locally on Apple Silicon — text chat only. 128 GB uses the hybrid 2-bit quant. 4-bit needs 256 GB.

在 Apple Silicon 上本地运行 GLM-5.3-Flash：仅文本对话。128 GB 用混合 2-bit，4-bit 需要 256 GB。

## Who it is for / when to care

给已经在 Mac 上用 NovaMLX 跑本地模型、并希望加载 GLM-5.3-Flash 文本量化的人。MacMaxPro 128 GB 用 `TensorFold/GLM-5.3-Flash-MLX-2bit-MTP`。mlx-community 4-bit（约 204 GB）要 256 GB 统一内存。需要图像或视频时，这次发布不适用。

## What shipped (user-visible behavior)

NovaMLX 可以按文本 LLM 下载并加载两条 preview 量化。`model_type` 为 `glm5_next`（文本 `glm5_next_text`）：混合 linear attention 与 sparse MLA、mHC、288 路专家 MoE。实现在 `Sources/NovaMLXEngine/Models/Glm5NextModel.swift`，注册名 `glm5_next` 与 `glm5_next_text`。

| 仓库 | 磁盘（目录标注） | 统一内存 | 索引 `metadata.total_size` |
| --- | --- | --- | --- |
| `TensorFold/GLM-5.3-Flash-MLX-2bit-MTP` | ~111 GB | 128 GB | 111,317,859,192 |
| `mlx-community/GLM-5.3-Flash-4bit` | ~204 GB | 256 GB | 203,992,076,296 |

本机 2-bit 可以已经在 `/Volumes/Samsung768/Models/TensorFold/GLM-5.3-Flash-MLX-2bit-MTP`。`nova download` 的 id 与上表 `org/repo` 相同。

思考和工具标记来自检查点 `chat_template.jinja`。工具 XML 形态是 `<tool_call>{name}<arg_key>…</arg_key><arg_value>…</arg_value></tool_call>`。加载时丢掉视觉权重和 MTP 层。上下文从检查点的 1,048,576 改写为 32,768。内存门：4-bit 需要 256 GB，混合 2-bit 需要 128 GB。

Z.ai 的文章（https://z.ai/blog/glm-5.3-flash）没有 Apple tok/s。社区参照是 oMLX 在 M4 Max 128 GB 上、`GLM-5.3-Flash-oQ2e-mtp`、4K 上下文大约 38.5 TG tok/s（https://omlx.ai/benchmarks/performance/0g84suc9）。那是社区天花板，不是官方数字，而且那次跑了 MTP。NovaMLX 短对话和 `Glm5SpeedTests` 打印 `GLM-CHAT`，预填充不算在内。云端 VM 跑不了这个测量。

## How to try it

```bash
nova load TensorFold/GLM-5.3-Flash-MLX-2bit-MTP
nova chat TensorFold/GLM-5.3-Flash-MLX-2bit-MTP
```

或：

```bash
NOVA_GLM53_MODEL=/Volumes/Samsung768/Models/TensorFold/GLM-5.3-Flash-MLX-2bit-MTP \
  ./build.sh test --filter Glm5SpeedTests
```

4K 预填充对照（仍是普通解码，不是 oMLX 的 MTP 跑法）：加上 `NOVA_GLM53_PROMPT_TOKENS=4096`。

## Limits / out of scope

- 图像、视频都不在这次发布里。视觉权重被丢掉。
- MTP 不是产品推测解码。检查点里的 draft 被忽略，因为没有 KDA 回滚验证。
- 没有 TIE 专家 SSD 流式。
- 不要说 1,048,576 上下文已经可用。实际上限是 32,768。
- 不要把 38.5 说成 Z.ai 公布的 Mac 速度，也不要写成 NovaMLX 已经达到的数字。
- 4-bit 需要 256 GB。128 GB 用混合 2-bit。
