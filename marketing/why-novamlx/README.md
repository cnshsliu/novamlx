# Why this model with NovaMLX — 宣传文案库

每个 NovaMLX 支持的大模型一份「为什么用 NovaMLX 跑它」宣传+性能报告，**供视频制作 Agent 按模型名读取**。

## 文件命名

`<模型关键字>.md`（小写、连字符），例如 `hunyuan3d.md`、`flint.md`、`qwen3-8b.md`。

## 每份报告的结构（视频脚本直接可用）

1. **一句话钩子** — 视频开头 3 秒抓人的那句话
2. **模型是什么** — 一段人话，不堆参数
3. **实测数据表** — 本机（注明硬件：M4 Max 128GB 笔记本）真实数字；对比行只放我们赢的维度，注明口径
4. **为什么是 NovaMLX** — 3-5 个差异化卖点，每个配一句"翻译成人话"的解释
5. **API 演示脚本** — 一段可直接录屏的 curl/代码
6. **画面/图表建议** — 视频里放什么图、什么对比条
7. **口号收尾** — 一句 slogan

## 数据纪律

- 所有数字必须来自真实测试（可复现命令附在报告里），**不编造**
- 本机跑不赢的维度（对比 8×H100 等）就不放，换维度打：隐私、零成本、离线、首 token 延迟、每美元性能、内存效率、开箱即用
- 口径永远写清楚："实测于 M4 Max 笔记本、4-bit 量化"
