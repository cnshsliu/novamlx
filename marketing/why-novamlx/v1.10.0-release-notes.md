# NovaMLX v1.10.0

**One app runs every modality — and now every model decides for itself whether it auto-loads.** Hardened the image and audio paths against degenerate input, and fixed host-side embeddings end to end.

**System Requirements:** macOS 15.0+ (Sequoia), Apple Silicon
**Download:** `NovaMLX-1.10.0-arm64.dmg` — signed + notarized

### What shipped since v1.9.0

- **Per-model auto-load switch.** Each downloaded model has its own Auto-load toggle on the Models page (loaded and unloaded rows). With the machine-wide switch on and a model's switch off, a client request returns HTTP 403 `model_autoload_disabled` instead of loading it; an already resident model still serves. Admin load, the Load button, and restart restore ignore it. `POST /admin/models/autoload` `{"modelId","enabled"}` flips it without a restart, and `/v1/models` reports `nova.autoload`.
- **A bad matte can no longer kill the host.** A 1×1 transparent PNG made the BiRefNet portrait mask NaN, and a `UInt8(Float)` trap took down every resident model. Mask and cutout bytes now clamp non-finite values, degenerate images (under 8×8, fully transparent, non-image bytes, over 8192 px a side) are rejected with HTTP 400 before a checkpoint loads, and the same gate covers edits, variations, and matting auto-load. Audio uploads over 64 MB or empty are 400; a non-finite TTS `speed` is rejected client-side.
- **Host embeddings show up in the loaded list.** `mlx-community/bge-m3-mlx-fp16` and any other loaded host embedder now appear on the Models page, the dashboard, and the menu-bar list, marked `host` to distinguish them from worker chat models. Exclusive chat load no longer unloads an embedding, and admin load / cold load / unload persist the id.
- **bge-m3 embeddings are correct.** The checkpoint now truncates to 256 tokens, pads with `<pad>`, and mean-pools with an attention mask before L2 — cosine against a reference mean-pool service went from ≈0.03 to 0.999998 / 0.999999 / 0.999996 (short / sentence / 1203-token texts, all 1024-d). Other embedding models keep the shared tanh CLS pooler.
