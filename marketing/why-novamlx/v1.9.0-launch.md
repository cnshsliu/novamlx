## 4. Forum post (V2EX / Reddit, English)

**Title:**

```

```

**Body:**

```
I've been chasing one setup: a coding agent that runs entirely on my own Mac. This week it went from "demo" to "actually finishes tasks", so here's the honest writeup.

**The stack**

- **Flint** — Recursive's 40B MoE agent model: chain-of-thought, multi-turn tool calls, 256K context. Built to be an agent, not a chatbot.
- **NovaMLX** — a native Swift/MLX inference server (no Python) that serves Flint behind standard OpenAI and Anthropic APIs. Menu-bar app, signed + notarized DMG.
- **OpenCode** — the coding agent, pointed at that localhost endpoint. Anything else that speaks OpenAI/Anthropic works the same way.

**The honest part: yesterday it was broken**

I pointed OpenCode at Flint and gave it real work. Every single tool call came back with empty arguments — the agent died on call #1, every time. Chinese replies garbled characters mid-sentence. Long answers sometimes looped until max_tokens.

That's what v1.9.0 fixes, and here's the measured result on the same three tasks (a bugfix, a CSV-stats feature, an LRU cache — with real file + shell tools, not benchmarks):

- Agent tasks: **0/3 → 3/3 pass**, 7–26 seconds each, fully offline.
- 8-article Chinese news condensing: **367 garbled characters → 0**.
- Chat decode: **~217 tok/s** on a 128 GB M4 Max (llama.cpp measured ~90 on the same class of model, for scale).

**Try it**

1. Download `NovaMLX-1.9.0-arm64.dmg` (macOS 15+, Apple Silicon).
2. `nova download RecursiveSI/flint-int4` (~23 GB) and let it load.
3. Point OpenCode (or any OpenAI-API client) at the local endpoint and give it a real task.

Your code, documents, and prompts never leave the machine, and there's no per-token bill.

Caveats, because I'd want them too: Apple Silicon only, macOS 15+, and you want comfortable memory headroom (~23 GB of weights). Speeds scale down from M4 Max. The model follows instructions better with clear tasks than vague ones.

Release notes: https://github.com/cnshsliu/novamlx/releases/tag/v1.9.0
Flint on NovaMLX: https://github.com/cnshsliu/novamlx/blob/main/docs/features/flint.md
```
